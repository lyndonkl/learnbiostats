# A mutation is a copying error that changes the base at a position, creating a new allele that did not exist before

When DNA is copied, the base at a single position (one rung) can be changed by
error, for example `C` to `T`. That produces a new allele — a variant — at that
position that did not exist before. Mutation is the ultimate origin of all
genetic variation: every variant base later counted in a genotype traces back to
some ancestral mutation.

A new mutation first appears in exactly one individual, and it is rare per
position per generation. It only becomes a common SNP if it spreads through the
population by inheritance over many generations. So mutation explains why a
variant exists at all; it does not, by itself, explain why a particular living
individual carries it (that is inheritance).
