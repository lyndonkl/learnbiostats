# Recombination assembles each chromosome passed to offspring as a patchwork of the parent's two copies

A parent carries two copies of each chromosome but passes only one to each
offspring. That passed-on copy is not a pristine duplicate of either copy.
During meiosis the parent's two copies are cut at a few points and segments are
swapped (crossover), so the copy handed down is a patchwork — for example,
positions 0–10 taken from one copy and 10–20 from the other.

Crucially, recombination changes no base, so it creates no new alleles. It only
produces new *combinations* of alleles that already exist. This is the clean
division of labour in inheritance: mutation creates new alleles; recombination
recombines existing ones into new arrangements before they are passed on.
